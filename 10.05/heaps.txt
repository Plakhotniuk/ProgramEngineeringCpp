1. Куча для максимума:

Куча для максимума — это бинарное дерево, которое удовлетворяет следующему свойству:
Для каждого узла i значение узла больше или равно значениям его дочерних узлов:
A[parent(i)] >= A[i], где A — массив, представляющий кучу, а parent(i) — родитель узла i.
Используется для быстрого извлечения максимального элемента, который всегда находится в корне дерева.

------------------------------------------------------------------------------------------------------------------------

2. Двоичная куча:
Двоичная куча — это куча, которая реализована в виде полного бинарного дерева
 (все уровни дерева заполнены, кроме, возможно, последнего, который заполняется слева направо). 
 Двоичная куча может быть:
- Max-Heap: Значение каждого узла больше или равно значениям его дочерних узлов.
- Min-Heap: Значение каждого узла меньше или равно значениям его дочерних узлов.
Двоичная куча часто используется для реализации приоритетных очередей и алгоритма сортировки Heapsort.

------------------------------------------------------------------------------------------------------------------------

3. Биномиальная куча:
Биномиальная куча — это набор биномиальных деревьев, которые удовлетворяют следующим свойствам:
- Каждое биномиальное дерево удовлетворяет свойству кучи (max-heap или min-heap).
- Для каждого неотрицательного целого k в биномиальной куче может быть не более одного биномиального дерева порядка k.
Биномиальное дерево порядка k:
  - Имеет 2^k узлов.
  - Высота дерева равна k.
  - Корень дерева имеет k дочерних узлов, каждый из которых является корнем биномиального дерева меньшего порядка.

Биномиальная куча поддерживает эффективные операции объединения, вставки и извлечения минимума/максимума.

------------------------------------------------------------------------------------------------------------------------

4. Фибоначчиева куча:
Фибоначчиева куча — это набор деревьев, которые удовлетворяют свойству кучи (max-heap или min-heap). 
Она обладает следующими особенностями:
- Деревья в фибоначчиевой куче не обязательно являются биномиальными.
- Каждое дерево удовлетворяет свойству кучи.
- Узлы могут иметь произвольное количество дочерних узлов.
Фибоначчиева куча поддерживает следующие операции с амортизированной сложностью:
  - Вставка: O(1)
  - Объединение: O(1)
  - Извлечение минимума/максимума: O(log n)
  - Уменьшение ключа: O(1)

Фибоначчиевы кучи используются в алгоритмы на графах. 
В частности, для задач построения минимального остовного дерева или поиска кратчайших путей из одной вершины
